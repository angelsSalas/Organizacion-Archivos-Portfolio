## Ecosistema de Proyectos
Este repositorio recopila las soluciones prácticas y arquitecturas de software limpias desarrolladas durante el semestre, las cuales demuestran de forma fehaciente la competencia de **"Evaluar diferentes organizaciones de archivos aplicándolas a situaciones reales"**.
