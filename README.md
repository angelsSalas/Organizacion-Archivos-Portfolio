## Ecosistema de Proyectos
Este repositorio recopila las soluciones prácticas y arquitecturas de software limpias desarrolladas durante el semestre, las cuales demuestran de forma fehaciente la competencia de **"Evaluar diferentes organizaciones de archivos aplicándolas a situaciones reales"**. A través de estos sistemas se abordó la manipulación, persistencia, lectura secuencial/indexada y optimización del almacenamiento de información, evitando malas prácticas como valores fijos incrustados en el código (*hardcoded*) y priorizando la eficiencia computacional en la administración de datos.
